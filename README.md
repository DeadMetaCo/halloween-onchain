# halloween-onchain

Official website source for **$HALLOWEEN** on Robinhood Chain.

## V1
Static HTML/CSS/JS site designed for Cloudflare Pages.

### Files
- `index.html` — page structure and launch copy
- `styles.css` — responsive visual design
- `script.js` — interactive doors, placeholders, and hidden 10/31 easter egg
- `assets/pumpkin.png` — approved orange pumpkin artwork
- `assets/favicon.png` — favicon

## Before launch
Replace the placeholder X / buy / chart / contract buttons when the official links are ready. The token parameters shown on the site reflect the working launch configuration and can be edited before deployment.

## Deploy
No build step is required. Cloudflare Pages can deploy this repository directly as a static site.
